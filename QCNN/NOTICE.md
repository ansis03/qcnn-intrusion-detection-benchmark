This directory vendors 4 files (`QCNN_circuit.py`, `Training.py`, `embedding.py`,
`unitary.py`) from Hur, Kim, and Park's QCNN implementation, unmodified:

- Source: https://github.com/takh04/QCNN
- License: Apache License 2.0 (see `LICENSE.md` in this directory)
- Paper: T. Hur, L. Kim, and D. K. Park, "Quantum convolutional neural network
  for classical data classification," *Quantum Machine Intelligence*, vol. 4,
  p. 3, 2022.

The original repository contains additional files (image-classification
data loaders, autoencoder preprocessing, benchmarking scripts, etc.) that are
not needed for this project and are not included here.
